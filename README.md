# El Rey de la Costanera

Juego de picadas con fierros argentos. Corré el cuarto de milla en la Costanera, mejorá tu auto en el taller y escalá el ranking del barrio hasta ganarle al Rey.

**Jugar:** https://pablog2081.github.io/rey-de-la-costanera/

Se juega desde el celular (o la compu). El progreso se guarda en el navegador.
